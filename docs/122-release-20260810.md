## 2026-08-10 SHP direct-load 勘誤

上述 release／完整版 hash 保留為當時已發布產物的歷史紀錄。後續確認 128／129 若要由
`DQ3MNS.SHP` 直接載入，除了四個色彩 plane 之外還必須附上原版 consumer 使用的逐列
RLE AND-mask；新的執行版副本已產生為 `work/DQ3MNS_fixed.SHP` 與
`dq3_remake_ebitan/mobile/assets/DQ3MNS.SHP`，SHA-256 均為
`eb846763ee5d5b1582d0e54678f238539b02e997f359f618d833ce8bac2b8adb`。本機原始
`assets_raw/DQ3MNS.SHP` 維持 SHA-256 `bad40e552343141b75191a5a9576adddb7a16ddf1378fe139eba4c4e15ba8bfd`；
既有 v0.1.33 release 未因本勘誤重包，下一次完整版封裝必須使用新的 patched copy。

## 重建與 release 界線

建置使用 `dq3-ebitan-test:latest`（Linux）、`dq3-ebiten-windows:20260810`（Windows）與
`u5cht/osxcross:latest`（macOS），依賴下載只在有界 Docker 網路中進行；原始素材唯讀掛載。
公開 release 只上傳上述四個 patch assets 與本文件所列 checksum，完整版僅作有合法素材的
本機測試。此輪沒有宣稱逐畫面、逐音效 V3 或完整長時間 campaign 測試通過。
