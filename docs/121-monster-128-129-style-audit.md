## 本輪產物與風格判定

`tools/make_sprites.py` 的目前規則已經把兩張外部參考圖量化到 `MNSBK.PAL` 前 16 色，並
以 `plane 3 → plane 0` 的順序寫回 SHP；`id 129` 的紫／藍色索引另外重映成實機可見的綠色。
重新執行後得到：

| 槽位 | 原始邏輯尺寸 | 展示 PNG（3× nearest） | SHA-256 |
| ---: | ---: | ---: | --- |
| 128 | 96×88 | [`spr_128.png`](monsters/spr_128.png)（288×264） | `6b0f75cd24886d01bb743cb7d59f9085587d1f16e2f2076ee80c2d616c8a6b47` |
| 129 | 128×96 | [`spr_129.png`](monsters/spr_129.png)（384×288） | `435679aa198f8daee1a7e6118dd2ded002a7081dd637de8b55bd0d4236528299` |

檢視結果：兩者均為透明背景、整數倍 nearest 像素、同一套 16 色 palette 與相同 SHP
plane 封裝；因此不需要用 AI 平滑、重畫輪廓或加入非原版色。可做且已完成的優化是把
README 聯絡圖改成與 130 格圖鑑相同的深色背景、索引框與像素縮放，避免灰底接觸表讓
兩隻外部回補圖看起來像另一套素材。這項展示優化不改變 sprite 位元組與遊戲邏輯。

## 發佈界線

公開 patch 包不含遊戲檔，也不含 `DQ3MNS_fixed.SHP`。本機完整版包會在複製使用者合法持有
的 `assets_raw/` 後，僅以回補 SHP 替換同名檔，再做雜湊與啟動檢查；原始目錄與工作檔不會
被覆寫。若未提供合法素材，完整版建置應失敗即關閉（fail-closed），不能用空檔或合理預設
代替。
