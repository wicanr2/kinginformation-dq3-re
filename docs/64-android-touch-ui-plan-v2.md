## 1. 動作集盤點(從完成後的 `InputState` 逐欄回查)

| 抽象動作 | 用在哪些情境 | 鍵盤 | 觸控現況 |
|---|---|---|---|
| 方向(按住) | 地表/城鎮走動(續走) | ↑↓←→ | ✓ 浮動十字鍵 |
| 方向(點按) | 命令窗/戰鬥/咒文/道具·裝備清單/設定/酒館各盤游標 | ↑↓←→ | ✓ 十字鍵邊緣觸發 |
| A · 確定 | 對話/開命令窗/對 NPC/選指令/施咒/用道具/裝備/調查/標題開始 | 空白 | ✓ A 鍵 |
| B · 取消 | 關面板/退子選單/出城/酒館返回/關設定 | Esc | ✓ B 鍵 |
| **切換** ↯ | 酒館命名:**英數盤 ↔ 注音盤** 切換 | `Tab` | ✗ **摸不到** |
| **設定** ↯ | 標題畫面開設定選單 | `S` | ✗ **摸不到** |

**核心結論修正**:`Toggle`(酒館注音切換)與 `Settings`(設定入口)各只綁一顆鍵盤鍵,觸控無對應
→ Android 玩家**無法幫角色取中文名、無法開設定**。這兩個缺口是 MVP 重點,其餘動作 dpad+A/B 已覆蓋。

## 2. 控制方案

1. **核心(已實作,`game/touch.go`)**:浮動十字鍵(左拇指,量化 4 向 + 死區)+ A/B(右拇指)。多點觸控、半透明、壓住高亮。
2. **補缺口(P1,MVP 通關必要)**:**情境鍵** —— 一顆位置固定、標籤隨情境變義的按鈕:
   - 標題畫面 → 「⚙ 設定」→ 觸發 `Settings`
   - 酒館命名階段 → 「注／A」→ 觸發 `Toggle`
   - 其餘情境 → 隱藏(不加多餘按鈕)
3. **增強(P2)**:選單直接點選(觸點座標 → 選項 index),十字鍵 + A 保底並存。最受益:注音盤、英數格、商店/道具清單。

### 情境鍵實作接法(不污染遊戲邏輯)
- `TouchUI` 加一個 context 按鈕:`ctxLabel`(空=隱藏,由 Game 每幀依情境設)+ `ctxTap`(edge)。zone 落在右上,與 dpad(左下)/AB(右下)不重疊。
- `InputState` 加 `CtxTap bool`(原始 context tap;來源無關)。
- Game:Update 起頭依狀態設 `ctxLabel`(showTitle→「設定」、tavern 且 stage==tavName→「注」、else 空);
  情境處理端把 `CtxTap` 映射成該情境的意義:標題 `Settings || CtxTap`、酒館 `Toggle || CtxTap`。
- 出城已由 B(Cancel)涵蓋,P1 不需額外鍵。
